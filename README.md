# myPrint — versioni pubblicate

Qui ci sono solo gli installabili di **myPrint** (diario di stampa e magazzino
filamenti per Bambu Lab) e le note di ogni versione. Il codice è in un repo privato.

## Scarica l'ultima versione

- **Windows**: https://github.com/filbussola/myPrint-releases/releases/latest/download/myPrint-setup.exe
  (avvialo: si installa senza permessi di amministratore)
- **Android**: https://github.com/filbussola/myPrint-releases/releases/latest/download/myPrint.apk
  (aprilo dal telefono; la prima volta Android chiede di permettere le app da fonti sconosciute)

Questi link puntano sempre all'ultima versione. Dopo la prima installazione l'app
controlla da sola le versioni nuove e si aggiorna dall'interno
(Impostazioni › Controlla aggiornamenti). Lo storico delle versioni è nelle
[Release](../../releases).
