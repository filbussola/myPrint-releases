# myPrint — versioni pubblicate

Qui ci sono solo gli installabili di **myPrint** (diario di stampa e magazzino
filamenti per Bambu Lab) e le note di ogni versione. Il codice è in un repo privato.

- **Android**: scarica `myPrint-X.Y.Z.apk` dall'ultima [Release](../../releases/latest) e aprilo.
- **Windows**: scarica `myPrint-X.Y.Z-setup.exe` e avvialo (nessun permesso di amministratore).

Dopo la prima installazione l'app controlla da sola le versioni nuove e si
aggiorna dall'interno (Impostazioni › Controlla aggiornamenti).
